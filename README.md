# Cleanpro Serviços - MVP

Repositório oficial do Minimum Viable Product (MVP) do sistema **Cleanpro Serviços**, desenvolvido para o gerenciamento e agendamento de serviços de limpeza e conservação.

---

## 🚀 Sobre o Projeto
O **Cleanpro Serviços** é uma aplicação web voltada para a otimização da rotina de agendamentos, permitindo o cadastro de clientes, gestão de serviços e controle de horários com uma interface intuitiva e arquitetura robusta.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Framework:** Flask (Arquitetura MVC/MVT)
* **Banco de Dados:** SQLite (evoluindo para PostgreSQL)
* **Controle de Versão:** Git e GitHub

---

## 📋 Requisitos Funcionais Atendidos (RF01 - RF04)
* **RF01:** Cadastro e autenticação de usuários (Clientes e Prestadores).
* **RF02:** Registro e gerenciamento de agendamentos de serviços.
* **RF03:** Consulta de histórico e status dos atendimentos.
* **RF04:** Painel administrativo para visualização de métricas e controle de horários.
